### **Guide de Création de Personnage Complet et Autonome pour Paranoïa**

Suivez ces 9 étapes pour créer votre premier Clarificateur. Prenez une fiche de personnage, un crayon et des dés (1D10 et 1D100, ou deux D10 de couleurs différentes).

#### **Étape 1 : Nommer le Personnage**

Le nom de votre personnage suit un format strict, dicté par l'Ordinateur.
**Format :** `Prénom - R - Code d'Unité - 1`
*   **Prénom :** Choisissez un prénom (ex: MAX, ANNA, JAN).
*   **R :** L'initiale de votre accréditation. Pour un débutant, c'est toujours **R** (ROUGE).
*   **Code d'Unité :** 3 lettres majuscules inventées pour votre secteur résidentiel (ex: CCL, DTS, THR).
*   **Numéro de Clone :** Vous commencez en tant que clone n°**1**.

> **Exemple :** `JAN-R-CCL-1`

#### **Étape 2 : Déterminer les Attributs Principaux**

Lancez les dés indiqués pour chacun des 8 attributs qui définissent les capacités de base de votre personnage.

*   **Force :** `1D10 + 8` (Puissance physique)
*   **Endurance :** `1D10 + 8` (Résistance physique)
*   **Agilité :** `2D10` (Coordination, esquive)
*   **Dextérité :** `2D10` (Habileté manuelle, précision)
*   **Adaptabilité :** `2D10` (Compréhension, perception)
*   **Aplomb :** `2D10` (Charisme, bluff, manipulation)
*   **Sens de la Mécanique :** `2D10` (Affinité avec la technologie)
*   **Indice de Pouvoir :** `1D10 + 5` (Puissance de votre pouvoir mutant)

#### **Étape 7 : Choisir et Calculer les Compétences**

Vous disposez de **6 points de compétence**.

**A. Répartition des Points :**
1.  **3 Points Obligatoires :**
    *   1er point : `Activités de Base (1)`
    *   2ème point : `Combat Armes de Tir (2)`
    *   3ème point : `Développement Personnel (1)`
2.  **2 Points de Spécialité de Service :** Investissez ces deux points dans les catégories autorisées par votre Service, en consultant la table suivante.
    **TABLE 3.7.6 : TABLE DES SPECIALISATIONS DES SERVICES**
    | Service | Catégories de compétences autorisées |
    | :--- | :--- |
    | Sécurité Interne | Activités de Base |
    | Services Techniques | Services Techniques |
    | PDH&CM | Développement Personnel |
    | Forces Armées | Activités de Base OU Services Véhiculaires OU Environnement hostile |
    | PLI | Services Techniques OU Véhiculaires |
    | Service de l'Energie | Services Techniques OU Véhiculaires |
    | Recherche et Conception | Services Techniques |
    | Unité Centrale de Traitement | N'importe quelle catégorie |
3.  **1 Point Optionnel :** Investissez ce dernier point où vous le souhaitez, en respectant la hiérarchie des compétences (vous ne pouvez pas prendre une compétence de niveau 3 sans avoir celle de niveau 2, etc.).

**B. Calcul du Pourcentage de Réussite :**
La chance de réussir une action se calcule avec la formule : `Pourcentage Final = Pourcentage de Base + Bonus d'Attribut`.

1.  **Calcul du Pourcentage de Base :**
    `Pourcentage de base = 15% + (5 x numéro de compétence)`
    Le "numéro de compétence" est le chiffre le plus élevé dans la branche de la compétence que vous utilisez.
2.  **Ajout du Bonus d'Attribut Secondaire :**
    *   **Bonus Armes de Tir :** Affecte les compétences de tir.
    *   **Bonus Mêlée :** Affecte les compétences de corps à corps.
    *   **Bonus Réparation :** Affecte les compétences techniques et de véhicules (sauf armes).
    *   **Bonus Compréhension :** Affecte les compétences d'environnement hostile (sauf armes).
    *   **Bonus Crédibilité :** Affecte les compétences sociales et de commandement.

> **Exemple de calcul :** DAVID-R-URK-1 a `Activités de Base (1)` et `Combat Armes de Tir (2)`. Il a une Dextérité de 13 (+5% Bonus Armes de Tir). Sa compétence de base avec un pistolet laser est de `15% + (5x2) = 25%`. Son score final est `25% + 5% = 30%`.

#### **Étape 9 : La Famille de Clones**

Votre personnage est le premier d'une série de **six clones identiques**. Si votre personnage n°1 meurt, le n°2 est activé. Ce nouveau clone repart avec les statistiques de départ de votre personnage original (attributs, compétences, secrets). Il ne bénéficie PAS de l'expérience, de l'équipement ou des promotions gagnées par son prédécesseur.
